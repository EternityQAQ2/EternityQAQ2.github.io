### 工具
用到的工具和包如下：


1.  系统        ：arch linux基础版本
2.  WM          ：niri
3.  qs主题      ：noctalia
4.  登录界面    ：sddm +美化 [silentSDDM](https://github.com/uiriansan/SilentSDDM)
5.  输入法      ：fxitx5 + rime + 美化 [Fluent-fcitx5](https://github.com/Reverier-Xu/Fluent-fcitx5)
6.  文件管理器  ：dolphin
7.  终端        : alacritty +konsole
8.  bash        ：zsh + oh my zsh + 美化powerlevel10k
9.  音乐播放器  : splayer
10. 快照        : btrfs assistant
11. 光标        : breeze
