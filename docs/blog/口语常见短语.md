# 常见词
- **lunes** - 周一
- **martes** - 周二
- **miércoles** - 周三
- **jueves** - 周四
- **viernes** - 周五
- **sábado** - 周六
- **domingo** - 周日

- **enero** - 一月
- **febrero** - 二月
- **marzo** - 三月
- **abril** - 四月
- **mayo** - 五月
- **junio** - 六月
- **julio** - 七月
- **agosto** - 八月
- **septiembre** - 九月
- **octubre** - 十月
- **noviembre** - 十一月
- **diciembre** - 十二月

- **Hoy** - 今天
- **Ayer** - 昨天
- **Mañana** - 明天
- **Ahora** - 现在
- **Luego** - 之后/一会儿
- **Temprano** - 早
- **Tarde** - 晚 / 下午
- **Noche** - 晚上

- **blanco** - 白色
- **negro** - 黑色
- **rojo** - 红色
- **azul** - 蓝色
- **verde** - 绿色
- **amarillo** - 黄色
- **naranja** - 橙色
- **gris** - 灰色
- **morado** / **violeta** - 紫色
- **rosado** - 粉色（拉美常用 _rosado_，西班牙常用 _rosa_）

- **casa** - 家/房子
- **cuarto** / **habitación** - 房间
- **cama** - 床
- **baño** - 卫生间/浴室
- **cocina** - 厨房
- **mesa** - 桌子
- **silla** - 椅子
- **puerta** - 门
- **ventana** - 窗户
- **llave** - 钥匙
- **celular** - 手机（拉美常用 _celular_，西班牙常用 _móvil_）
- **computador** / **computadora** - 电脑

- **agua** - 水
- **café** - 咖啡
- **leche** - 牛奶
- **pan** - 面包
- **arroz** - 米饭
- **pollo** - 鸡肉
- **carne** - 肉（通常指牛肉）
- **pescado** - 鱼
- **fruta** - 水果
- **verdura** - 蔬菜
- **desayuno** - 早餐
- **almuerzo** - 午餐（拉美最重要的一餐）
- **cena** - 晚餐
- **cuenta** - 账单（吃饭结账时说 _"La cuenta, por favor"_）

- **ser** / **estar** - 是（_ser_ 表本质，_estar_ 表状态/位置）
- **tener** - 有
- **hacer** - 做
- **ir** - 去
- **venir** - 来
- **comer** - 吃
- **beber** / **tomar** - 喝（拉美常用 _tomar_ 表示喝）
- **dormir** - 睡觉
- **trabajar** - 工作
- **estudiar** - 学习
- **hablar** - 说话
- **entender** - 理解/懂
- **querer** - 想要 / 爱
- **poder** - 能/可以
- **necesitar** - 需要

- **feliz** - 开心
- **triste** - 伤心
- **enojado** / **bravo** - 生气（_bravo_ 在哥伦比亚很常用）
- **cansado** - 累
- **hambre** - 饿（注意：名词，说 _"Tengo hambre"_）
- **sed** - 渴（名词，说 _"Tengo sed"_）
- **frío** - 冷
- **calor** - 热

- **bus** / **autobús** - 公交车
- **taxi** - 出租车
- **metro** - 地铁（麦德林有，波哥大正在建）
- **transmilenio** - 快速公交系统（波哥大特有，口语常说 _"el Transmi"_）
- **aeropuerto** - 机场
- **avión** - 飞机
- **boleto** / **tiquete** - 票（拉美常用 _tiquete_）
- **pasaporte** - 护照
- **maleta** - 行李箱
- **dirección** - 地址/方向
- **mapa** - 地图
- **parada** - 车站/停靠点


- **cabeza** - 头
- **ojo** - 眼睛
- **boca** - 嘴
- **mano** - 手
- **pie** - 脚
- **estómago** - 胃
- **espalda** - 背
- **dolor** - 疼痛（说 _"Me duele..."_ + 部位）
- **medicina** / **medicamento** - 药
- **hospital** - 医院
- **farmacia** - 药店
- **cita** - 预约（看医生或办事都说 _"tener una cita"_）

- **sol** - 太阳/晴天
- **lluvia** - 雨
- **nube** - 云
- **viento** - 风
- **calor** - 热
- **frío** - 冷
- **temperatura** - 温度
- **hoy hace sol** - 今天晴天
- **está lloviendo** - 正在下雨
